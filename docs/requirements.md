# 需求說明

## 專案背景

本專案為軟體工程課程的 Agile + AI 期中專案，團隊共 3 人，預計開發約 2 週。

## 預計功能範圍

1. 使用者登入，區分教師與學生角色。
2. 教師建立課程。
3. 教師發布課程公告。
4. 教師與學生在課程留言板發言。

## 技術選擇

- 後端：Python Flask。
- 前端：HTML、CSS、Bootstrap。
- 資料庫：SQLite（尚未整合）。
- 模板引擎：Jinja2。
- 版本控制：Git。

## 本階段交付範圍

僅建立資料夾、預留檔案、共用模板與可顯示的首頁；不實作上述功能、不建立完整資料模型。詳細規則與驗收條件待團隊確認。
