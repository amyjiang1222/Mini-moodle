# Mini Moodle 視覺方向（本地草稿）

對象是教師和學生；首頁首要任務是找課程。沿用 Amy 原本的藍色品牌，將頁面改為課程目錄，而不是相同尺寸的卡片集合。

- 色彩：校務藍 `#16447E`、深藍 `#18304C`、紙白 `#F8FAFD`、淺藍 `#EAF1FA`、分隔線 `#CCD7E5`、提示黃 `#F3C85D`。
- 字體：`Noto Sans TC`／`Microsoft JhengHei`，以重量和大小區分層級。
- 版面：頁首、左對齊標題、課程列表；教師建立與學生加入課程的動作放在列表旁。
- 原則：分隔線表示課程列，黃色只表示焦點；避免漸層、陰影與大量圓角。

初稿曾考慮米白底、襯線標題和陶土色，但這也是目前常見的 AI 設計套件，且與原本的藍色介面沒有連續性。因此改用課程目錄結構。參考 Anthropic `frontend-design` skill；本稿待使用者審閱。
